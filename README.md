# 🐾 Telegram-бот «Блог Марселя»

Проект — простой Telegram-бот, написанный на **Python** и управляемый с помощью **uv**, который ведёт уютный блог от имени кота по имени **Марсель**.

## 📌 О проекте

Бот позволяет пользователям читать «записи» Марселя — 9-летнего шотландского кота, который делится своими мыслями, привычками, хобби и жизнью.
Сам бот простой и лёгкий, подходит как пример работы с Telegram API.

## 🚀 Технологии

* **Python**
* **uv** — для изоляции окружения и установки зависимостей
* **pyTelegramBotAPI (telebot)** — для взаимодействия с Telegram Bot API
* **dotenv** — для скрытого хранения токена

## 🛠 Установка и запуск

### 1. Установка uv

Если uv ещё нет:

```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2. Установка зависимостей

```
uv sync
```

### 3. Создание `.env`

Создай файл `.env` и добавь туда токен своего Telegram-бота:

```
BOT_TOKEN=your_token_here
```

### 4. Запуск бота

```
uv run main.py
```

## 🐈 Возможности бота

* Показывает приветственные сообщения от имени Марселя
* Делится его «хобби»
* Может отправлять картинки котика
* Содержит небольшой мини-блог
* Лёгкая архитектура — удобно расширять
